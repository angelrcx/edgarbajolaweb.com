# Artista Web

## Desarrollo
npm install && npm run dev

## Agregar un álbum
1. Subir la portada a `src/assets/musica/`.
2. Duplicar un JSON en `src/content/albumes/` y editarlo.
3. Subir los cambios a GitHub; Cloudflare publica solo.

## Despliegue (Cloudflare)
Build command: `npm run build` — Output directory: `dist`
